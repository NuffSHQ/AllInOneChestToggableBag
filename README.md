# LuiAFK Reborn: AIO Chest & Merchant QoL

A quality-of-life addon for Terraria that extends the functionality of the **Mobile All-In-One Chest and Merchant** item from the LuiAFK Reborn mod. 

This mod allows players to dynamically toggle the Mobile All-In-One Chest and Merchant void bag inside the inventory.

---

## 🚀 Key Features

* **Instant Void Bag Toggling:** Simply right-click while hovering over the Mobile All-In-One Chest and Merchant item in your inventory to instantly open or close your Void Bag.
* **Dynamic Tooltip Cues:** The item's tooltip updates in real-time to reflect whether your Void Bag is currently open or closed.
* **Sprite Change:** Changes the item's sprite dynamically based on the current open/closed status of the void bag.

---

## 🛠️ Requirements & Dependencies

This mod functions as an addon and requires the following to run properly:
* **tModLoader** (Terraria 1.4.4)
* **LuiAFK Reborn** (Internal name: `miningcracks_take_on_luiafk`) [2]
